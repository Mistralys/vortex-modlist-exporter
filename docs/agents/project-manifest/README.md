# Project Manifest — Vortex Mod List Exporter

**Package:** `mistralys/vortex-modlist-exporter`  
**Purpose:** A PHP CLI tool that reads a Vortex mod manager database backup and produces a structured JSON mod list plus human-readable Markdown reference documents (mod list and tag reference) for each configured game.
